# MLB Multi-Market Coverage Expansion v1

This research block asks whether independent MLB market families can recover strict A+ / Premium parent-route NO_PLAY dates without relaxing the existing Daily BEST PICK hierarchy.

The protocol was frozen before the outcome scorer. The exact study scope is:

- Full Game Moneyline
- First 5 Moneyline
- Full Game Run Line
- First 5 Run Line
- Full Game Total
- First 5 Total
- First 3 Run Line
- First 3 Total

Training is 2022, validation is 2023, and 2024 + 2025 + 2026 YTD are frozen out-of-sample evaluation seasons. The quality-volume frontiers are Q80, Q85, Q90, and Q95, with thresholds derived from the 2023 positive model-vs-2022-baseline signal distribution only. All frontiers are reported; no post-outcome frontier selection is permitted.

This study is research only. It does not change A+, Premium, V68, V80, production ranking, settlement, odds acquisition, staking, or automatic betting. It does not use historical prices and therefore cannot establish positive EV. Any union coverage number is an opportunity ceiling, not an executable one-pick-per-day recommendation rate.
